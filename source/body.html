1. Four families: what each one learns

Memory hook: value-based asks "how good is this place", Q-based asks "how good is this move", policy-based just acts, and actor-critic acts and then gets graded.

ApproachLearnsMain questionHow it picks an actionExample algorithms
Value-based$V(s)$"How good is this state?"Picks the action whose next state looks best. That needs a model to look one step aheadValue iteration, policy evaluation, TD(0)
Q-based (action-value)$Q(s,a)$"How good is taking this action in this state?"Picks the action with the highest $Q$. No model neededQ-learning, SARSA, Expected SARSA, Double Q-learning, DQN
Policy-based$\pi(a \mid s)$"What action should I take?"Samples straight from the policyREINFORCE (vanilla policy gradient)
Actor-critic$\pi(a \mid s)$ plus $V(s)$ or $Q(s,a)$"What action should I take?" plus "How good was that decision?"The actor samples an action, the critic scores itPPO, A2C, A3C (critic learns $V$). DDPG, SAC (critic learns $Q$)

Two traps examiners use. First, knowing only $V(s)$ does not tell you which action to take unless you have a model, which is why model-free control learns $Q(s,a)$. Second, REINFORCE with a baseline also learns $V(s)$, but only to reduce variance, never to bootstrap, so it is still policy-based, not actor-critic.

Viva questions on bias and variance

Why is MC unbiased but high variance? It uses the true return from a complete episode, so on average it is exactly right. But that return adds up many random rewards and actions, so one episode can be far from the average.

Why is TD lower variance but biased? It uses one real reward plus its own estimate of the next state. Only one random step is involved, so variance is lower. The estimate may be wrong, which adds bias until it improves.

Memory chain

  • DP = model-based + bootstrap + usually synchronous
  • MC = model-free + no bootstrap + high variance
  • TD, SARSA, Q-learning = model-free + bootstrap + one step at a time
  • SARSA and PPO = on-policy. Q-learning and DQN = off-policy
  • MCTS and AlphaZero = model-based planning, and only AlphaZero bootstraps

What was corrected, and why

  1. PPO collects experience in synchronous batches. The asynchronous one is A3C. Saying PPO is asynchronous is an easy mark to lose.
  2. AlphaZero does bootstrap. Its leaf values come from the value network, an estimate, in place of rollouts. Plain MCTS backs up real rollout returns, Monte Carlo style, so it does not.
  3. DP has no sampling variance at all. It averages over the exact model, so "low" undersells it. Its only error is the starting guess, which the sweeps remove.
  4. TD(0) is on-policy. "Prediction" answers a different column. TD(0) evaluates the policy that generated the data.
  5. Synchronous and asynchronous describe DP sweeps. Calling TD asynchronous is a fair comparison, since it updates only the state it visits, straight away. The precise words are online and sample-based.
